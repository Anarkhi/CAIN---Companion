# CAIN Companion

A digital companion web app for the CAIN tabletop RPG system (v1.4.5), plus GFF expansion content.

## Play it

Open the published site and everything runs in your browser — characters are saved locally in your browser's storage (localStorage) and can be exported/imported as JSON.

## Features

- Guided character creation (skills, agenda, blasphemy)
- Character management: view, edit, and track in-play state (stress, injuries, sin, psyche bursts, etc.)
- Compendium: browse Agendas, Blasphemies, and Virtues
- Real-time language toggle between English and Brazilian Portuguese
- No account or server needed — fully client-side

## Running locally

Just open `docs/index.html` in any modern browser. No build step, no server, no dependencies.

## Tech

Vanilla JavaScript, no framework, no build step. All app code lives in `docs/`.
