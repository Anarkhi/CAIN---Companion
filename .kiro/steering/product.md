# CAIN Companion

A digital companion web app for the CAIN tabletop RPG system (version 1.4).

## Purpose

Provide players and game masters with a browser-based tool for:
- **Character creation** — guided multi-step wizard following CAIN's rules (skills, agenda, blasphemy).
- **Character management** — view, edit, and track in-play state (stress, injuries, sin, psyche bursts, etc.).
- **Portability** — characters saved in the browser (localStorage) and exportable/importable as JSON files for sharing.
- **Internationalization** — real-time language toggle between English and Brazilian Portuguese (PT-BR).
- **Modularity** — game data files are structured for easy expansion with custom/homebrew content.

## How to Use

Open `app/index.html` in any modern browser. No internet connection or server required.

## Reference Material

- `Referencias/CAIN_1.4.txt` — Plain text version of the CAIN 1.4 rulebook. Use this for referencing rules, mechanics, and content.
- `Referencias/CAIN 1.3 Tradução PTBR.txt` — Fan translation to Brazilian Portuguese (by ZackVanHellsing, Jonas & LadyBatatita). Used as reference for PT-BR game terminology.
- `Referencias/CAIN_1.4_spreads.pdf` — The CAIN 1.4 rulebook in spread/PDF format (not machine-readable).
